# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅        |
| < 1.0   | ❌        |

## Reporting a Vulnerability

Please do **not** open public issues for suspected security bugs.

Instead, report directly via email (see profile) or GitHub private vulnerability advisory.

We will acknowledge within 48 hours and aim to patch within 14 days.
